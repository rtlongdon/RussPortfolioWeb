GreatEFB

Moving Map Electronic Flight Bag for Experimental Aircraft

Real-Time Flight Data

Tablet GPS provides position and altitude*. Add Dynon SkyView for magnetic heading, accurate pressure altitude, and live traffic data.

Integrated Flight Planning

Create and edit flight plans, with automatic weather and NOTAM retrieval along your route.

Comprehensive Weather

FIS-B (over-the-air) and ground-fetch weather: METAR, TAF, PIREP, AIRMET, SIGMET, G-AIRMET, CWA.

Terrain Awareness

Real-time elevation tiles with aircraft-altitude-based color coding — red for hazard, yellow for caution.

Traffic Display

ADS-B and TIS-B traffic with alert status, relative bearing, altitude, and distance from your aircraft.

Offline Capability

Download charts, terrain, and airspace data to your tablet — no internet required in flight.

Built-In Features

  • Manual data sync for charts, terrain, airspace, airports (requires internet connection)
  • Sectional, TAC, and flyway charts
  • Class B/C/D/E airspace with vector outlines
  • Airport detail sheets with runways & frequencies
  • Navaids and instrument fixes
  • TFRs with linked NOTAM text
  • Direct-to waypoint navigation
  • Rubber-band waypoint editing in-flight
  • Heading, track, groundspeed, altitude display
Platform Android tablets with GPS (portrait & landscape)
Min SDK Android 7.0 (API 24)
Avionics (Optional but recommended) Dynon SkyView with WiFi module
Data Sources FIS-B + aviationweather.gov

* Some tablets have built-in magnetic compasses, but GreatEFB does not use them due to calibration challenges in aircraft environments where magnetic interference is common.

GreatEFB is for VFR use only. Always conduct thorough preflight weather briefings and flight planning. Not a replacement for certified avionics or flight planning procedures.
