GreatEFB Data Pipeline

The offline data pipeline that builds GreatEFB's map data — sectional charts, airspace, airports, and elevation tiles from FAA source data.

Stable

Living portfolio — everything subject to change.

What it does

GreatEFB doesn't fetch or render its own map data live — it ships with pre-built regional data generated offline by this pipeline. It's built specifically to feed GreatEFB, but it's a substantial project in its own right: pulling FAA source data, converting it into app-ready formats, and serving it to the tablet.

Why is the pipeline necessary?

Aviation data exists, but not in a format a tablet can efficiently display. The FAA provides sectional charts as huge raster images, airspace as shapefiles, and airport data in CSV format. These raw sources are too large and unsuitable for real-time processing on a tablet. The pipeline solves this by preprocessing everything once: chopping charts into map tiles, baking elevation into compact image formats, and indexing airspace/airport data into searchable databases. The tablet receives pre-digested data it can render instantly, without needing an internet connection or doing heavy computation mid-flight.

Highlights

  • Chart Generator converts FAA sectional charts into optimized MBTiles using GDAL
  • Elevation baking produces grayscale elevation tiles, region by region
  • Airspace Builder pulls Class B/C/D/E and Special Use Airspace from the FAA's ArcGIS REST API into regional SQLite databases
  • AIS Builder builds airport/navaid supplement databases from FAA NASR/NFDC data
  • A Flask-based regional HTTP server serves the built data (elevation, charts, airports, navaids, airspace) to the GreatEFB tablet app
  • Script Director orchestrates the whole pipeline — elevation bake, airspace/AIS builders, NASR download+parse, and the update server
  • All data is organized into regions aligned with the FAA's chart supplement regions
