Secondary Flight Display

A production-grade secondary flight display for Android tablets, designed to run alongside a Dynon SkyView avionics system on an RV-12.

In development

What it does

Displays real-time flight data from SkyView via UDP, or replays recorded flights from Dynon datalog CSV exports — a full glass-cockpit backup display rendered at 60 FPS.

Highlights

  • Live SkyView integration over UDP (Type 3 ADAHRS packets, port 8384)
  • Datalog replay with a timeline scrubber for reviewing past flights
  • Glass cockpit instruments: attitude indicator, VSI, airspeed, altitude tape, turn coordinator
  • Calculated rate-of-turn from heading deltas
PlatformAndroid (Kotlin, landscape locked)
Data sourceDynon SkyView UDP + CSV datalog replay
RenderingJetpack Compose + Canvas @ 60 FPS
Built for experimental aircraft running Dynon SkyView.
