ADAHRS Project

An experimental attitude and heading reference system (ADAHRS) for experimental aircraft — backup attitude instrument design with sensor fusion and real-time filtering.

Early stage

What it is

A minimal, standalone backup attitude instrument designed to keep the pilot upright if the primary system fails. Rather than a full ADAHRS system, the scope is deliberately narrow: attitude (pitch/roll) + altitude + vertical speed, with a sensor suite that includes IMU (gyro + accelerometer), GPS for yaw reference and VSI cross-check, and barometric pressure for altitude.

Architecture

  • IMU-based core: 9-DOF gyro + accelerometer for attitude and slip detection
  • Redundant yaw: GPS velocity vector (coordinated flight above minimum groundspeed) as the yaw reference
  • Altitude and VSI: Barometric pressure sensor for altitude and vertical speed indication
  • Deliberate exclusions: No magnetometer (eliminates hard/soft iron calibration), no airspeed sensor (no pitot-static tap needed)

Current Phase

Sensor selection and architecture under active review. Learning focus: IMU sensor fusion, Kalman filtering for attitude estimation, GPS velocity noise characterization, and pressure altitude resolution for VSI applications. Core mathematics study includes refresher on matrix and quaternion representations of aircraft and earth reference frames, essential for attitude transformation and filtering.

Next Steps

  • Sensor evaluation and prototype board layout
  • Attitude estimation filter implementation (EKF or complementary filter)
  • Real-time firmware development (C/C++ on microcontroller)
  • Flight-test validation and integration with existing avionics
